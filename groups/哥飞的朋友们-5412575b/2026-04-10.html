给大家秀一下哥飞的几个网站，经历了谷歌3月搜索算法更新后，不仅流量没跌，反而涨了。 核心理念就是理解谷歌底层算法机制，与谷歌目标一致，努力去满足谷歌用户的搜索需求，这样谷歌自然就会喜欢我们的网站了。 谷歌利用全球站长的无数个网页来满足自家搜索用户的搜索需求，谷歌需要站长的网页，站长也需要谷歌，两者是合作共赢的关系，双方一起共建生态。 但是那么多站长做了那么多网页，到底谁的网页要排到前面呢？ 这就是 SEO 要做的工作了，得让谷歌的爬虫能爬到我们网页，得一次请求就在 html 里把网页内容返回，得让谷歌能够抽取网页内容，得让谷歌能够识别到网页主题，得让谷歌能够建立索引，得让我们的网页有竞争力，得有外链，得有权重。 但很多人做网页有个误区，只做功能，不写内容，或者乱写内容。 谷歌又没办法去测试你的功能，完全不知道你网页能够提供什么的功能，于是就无法索引你的网页，无法在搜索结果里推荐你的网页。 这是很简单的道理，但是真的有很多人不懂。 所以做好 SEO 有多难吗？其实不难，难的是得有这样的意识。

转自志达：
付费看完了 codex 团队的采访， 说下我认为的重点:

• 团队只有 40人，就 1个 pm， 2个designer，其余全是 eng➕少量 researcher。

• 唯一一个 pm 的 routine就是用 codex 来处理用户反馈，issue，排优先级。一小时自动跑完一次，处理 100+issue，大部分 24 小时内修复。

• feature 都是极小团队（2-3 人），甚至单人完成，从规划到发布，再到迭代。

• 几乎没有定期会议了，全是点对点直接沟通，没任何流程，没啥管理成本。

• codex 协助新人 onboard，从电脑配置到项目和上下文同步

• 99% 代码是 codex 生成，每个工程师至少 4个并行 agent。一个在做 code review，一个在实现功能，一个在跑安全审计，一个在生成代码库摘要。

• 团队总leader 自己搞了个automation，每天多次随机选一个代码文件，让 agent 去找隐藏 bug 并提交修复。另一个 automation 每天自动搜索全网用户对产品的讨论，生成营销情报简报。

个人印象最深的地方:

• 我觉得大 leader 如果不做向上管理，唯一那个 pm 的活他自己就能干完…

• 协作成本急剧降低了，因为不需要协作了…大部分跨职能分工协作的活，agent 给你保证了下限，快速迭代的时候可以接受。

• 老外也搞 pr 排行榜…这很中国，有一个每日贡献报告：每天早9点自动汇总前一天所有合入 Codex app 的 commit。

• 还是不够聚焦，anthropic 一千多号人在编程模型和产品的专注度是超过 OpenAI 的，创业公司跟大平台竞争，大平台针对你这个方向的团队人数是没你多的。

傅盛的文字分享 — _傅盛_

今天朋友圈突然被SBTI人格测试刷屏了，又是FAKE又是MUM的五花八门什么都有。据说有三百多万人测过，网站都一度被挤崩了。我顺手让三万把源码翻了一遍，发现了三件挺有意思的事。第一件：这个测试，你没法作弊做过MBTI的人都知道，那种测试其实能引导结果。哪道题在测I还是E，你大概心里有数，想往哪个方向走，选对应选项就行了。SBTI不是这么做的。它用了一个叫pattern distance的算法。不是在统计你"选了什么选项"，而是把你所有题的整体作答模式，和每一种人格类型的标准模式分别做距离计算，看你"最像谁"。所以你根本不知道哪道题在测哪个维度。你想"演"，你都不知道在哪里演。第二件：暗门是两步的大家应该已经知道了，这套测试是作者为了劝一个爱喝酒的朋友戒酒做的，里面有一道陷阱题，选了喝酒就铁定测出DRUNK/酒鬼人格。但我翻源码发现，这个暗门不是一步，是两步的。第一道："您平时有什么爱好？" 选项：吃喝拉撒 / 艺术爱好 / 饮酒 / 健身只有选了"饮酒"，下一道题才会出现。其他选项，你根本不知道这道题的存在。然后第二道才出现："您对饮酒的态度是？"先问你有没有这个爱好，再问态度。只有真的"把白酒当白开水喝"的人才会中招。她那个朋友大概就是这个级别的。第三件：越无厘头的题，测的越正经有个题目是这样的："你因便秘坐在马桶上（已长达30分钟），拉不出很难受。此时你更像——"做这道题我只觉得……挺抽象的。翻代码才发现，这道题的维度标签是执行力，你面对这件事的方式，就是你做事的方式。第22题更绝。题目只有一句："此题没有题目，请盲选"完全没有任何信息，不告诉你在测什么、选哪个代表什么。翻到维度定义，才知道它测的是面对不确定信息时的决策方式。你对"完全不知道"这件事本身的反应，就是答案。我自己做产品这么多年，见过太多东西越改越复杂、越改越没人记得。这套东西反过来，越看越觉得，有些时候把一件事做对，比把一件事做大要难得多。
