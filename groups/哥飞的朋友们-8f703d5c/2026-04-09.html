Claude 出了一个 Managed Agents 服务，这其实是一个云端智能体服务平台，你看他博客介绍可能不太好理解，我说一个理解方式，大家一听就懂。

为了保 Claude 账号，避免因为环境问题导致被封号，我都是直接在网页版里用 Claude Code ，地址是 https:// claude.ai/code ，把 GitHub 仓库授权给他后，他会自动把代码拉取到云端，然后根据仓库里指定的需求文件如 Claude.md 或者 Design.md 自动执行任务，把代码写完。

我用这种方法做了之前跟大家分享过的自动外链浏览器插件，以及几个网站代码，全程我都不看代码，只做测试就行，测好之后再把修改反馈告诉他，他就自己去修改代码。

改完代码了，他会自己提交代码，我可以让他创建 PR，然后自己点击链接到 Github 网站合并 PR，也可以我自己手动创建 PR 后合并，全程都是在网页里实现，不会用到我自己电脑环境。

我还可以同时开多个会话，一个会话就是一个分支，每个分支各自做不同的功能，这样就相当于几个人一起配合写代码，各自分工，写完后各自提交到自己的分支，我再去创建 PR 合并代码。

遇到分支之间代码冲突，也不需要我自己去解决冲突，我直接告诉他，现在有冲突了，你解决一下，他就会调用 Git 命令查看冲突，然后修改冲突，提交代码，我再去合并代码。

也就是说，除了合并代码到主分支这一步需要我自己操作，剩下的他全都可以自己干。

而 Managed Agents ，其实就可以理解为 Claude 把云端 CC 能力做成了 API，提供给用户使用。

收费挺贵的，分三项收费：
1.消耗的 Token 按照 API 价格计费；
2.运行时要 0.08美元每个会话小时；
3.搜索服务额外收费，要10美元每千次搜索。

这种计费折算成人员工资，有些企业就会觉得便宜了，但如果不是用于能够创造价值的任务，那就挺贵的，不划算。

不过我们群友们用来自动上站，我觉得就不会嫌贵了，因为网站最终能够创造收益，完全可以覆盖这部分成本。

但我觉得，对于我们来说，其实直接用网页版的 CC 也许是更省钱的做法，100刀一个月或者200刀一个月的套餐，实际能够花出去的 Token 是几千美金，比用 API 划算多了。
