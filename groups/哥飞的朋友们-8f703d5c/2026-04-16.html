举例来说，某个需求，搜索量最大的表达是“A B C”，但其实还会有人搜索“A B”、“B A”、“B C”、“B C A”等等各种词。

那些大厂做网页，他们会挑选搜索量最大的“A B C”来写页面内容文案。

还剩下一些别的表达，他们可能会在页面的 H2或者 H3 来覆盖，但是大概率不会专门上一个页面来覆盖，更不可能单独做一个网站来覆盖。

如果此时，没有别的网页去做别的表达，那么不管用户搜索“A B C”、“A B”、“B A”、“B C”、“B C A”中的哪个词，搜索结果里出来的都是标题里含有“A B C”的页面。

因为谷歌其实是有语义理解能力的，知道用户要找的是什么，即使标题不是完全匹配，也会在搜索结果中返回。

17:47:18 · 哥飞 · 文本

这就是我们个人站长的机会，我们可以去瞄准某个表达来上站。

举例我们可以用 “B C A” 来注册域名，然后举全站之力来优化“B C A”这个词，网站首页的 TDH 就是瞄准“B C A”这个说法去做的。

不断的上内页，不断的搞外链，慢慢的会发现，我们能够拿到一些关键词的排名了，有曝光有点击。
再继续搞外链，会发现排名继续上升，会拿到更多关键词的曝光。
最终你会发现，有一天，你能够拿到“A B C”的靠前排名。
